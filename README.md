# Smart Home Automation Using Deep Learning

An AI-powered Smart Home Automation system developed using Raspberry Pi, ESP32-CAM, Python, OpenCV, and Flask. The project performs real-time face detection and recognition for secure access while monitoring environmental conditions through IoT sensors. It automates home appliances based on sensor data and provides a web dashboard for monitoring and control.

## Technologies Used
- Python
- OpenCV
- Flask
- Raspberry Pi 4
- ESP32-CAM
- LBPH Face Recognition
- YuNet Face Detection
- Git

## Features
- Real-time face detection and recognition
- Smart appliance automation
- Environmental monitoring
- Live camera streaming
- Web-based monitoring dashboard
